# 韩语学习

面向中文用户的韩语学习应用，通过汉字联想帮助记忆韩语词汇，目前收录 117 个词语并持续更新。

## 在线体验

**[立即开始学习](https://echohux.github.io/Korean-Vocabulary-Study/)**

无需下载安装，也不需要配置开发环境。

## 核心功能

- 学习韩语单词、罗马音、简体汉字和中文释义
- 通过“记住 / 没记住”或左右滑动完成自评
- 根据记忆情况自动安排 SRS 复习
- 反向练习：根据中文和汉字回忆韩语
- 酒店、医疗、旅游、餐厅等生活场景句
- 离线例句与中文语法讲解
- 韩语单词和句子朗读
- 学习进度、复习趋势和记忆曲线

## 学习流程

### 学新词

选择学习范围，查看韩语词和罗马音，听取发音并显示答案，然后选择“记住”或“没记住”。

### 复习

到期词汇会进入复习队列。选择“没记住”后，该词会立即再次进入复习队列。

### 反向练习

根据中文和简体汉字回忆韩语词，用于额外强化记忆，不改变正常复习计划。

### 句子学习

按酒店、帮助／医疗、旅游和餐厅场景学习韩语句子、中文翻译与重点词。

## 数据与隐私

学习记录保存在当前浏览器的 IndexedDB 中：

- 数据库：`korean-hanja`
- 数据表：`reviews`
- 数据不会自动上传，也不会跨设备同步
- 清除网站数据、更换浏览器或使用无痕窗口会导致记录消失

## 朗读功能

如果存在预生成音频，优先播放静态音频；否则使用浏览器或系统提供的韩语 TTS。不同设备可用的音色可能不同。

## 常见问题

### 看不到最新版本怎么办？

尝试强制刷新：

- macOS：`Command + Shift + R`
- Windows：`Ctrl + F5`
- 手机：关闭页面后重新打开

### 为什么换设备后没有学习记录？

学习记录仅保存在当前浏览器，没有接入账号或云端同步。

### 为什么例句可以离线显示？

例句和中文语法讲解已经写入静态资源，运行时不需要调用模型或网络接口。
