# 韩语汉字词学习 H5 使用说明

## 一、产品简介

这是一个面向中文用户的韩语学习 H5，重点帮助学习者通过汉字联想记忆韩语词汇。

主要功能：

- 学习韩语单词
- 查看韩语罗马音、简体汉字和中文释义
- 通过左右滑动进行“记住 / 没记住”自评
- 按记忆情况自动安排复习
- 反向练习：看中文和汉字回忆韩语
- 学习酒店、医疗、旅游、餐厅等生活场景句
- 查看例句和中文语法讲解
- 朗读韩语单词和句子
- 查看学习数据和记忆曲线

## 二、在线访问

在线地址：

<https://echohux.github.io/Korean-Langurage-Study/>

使用在线版本不需要安装 Node.js、pnpm 或其他开发工具。

## 三、下载 ZIP 后使用

### 1. 解压文件

解压 `korean-hanja-h5.zip`，进入解压后的目录。

解压后应能看到：

```text
index.html
assets/
audio/
favicon.svg
```

### 2. 启动本地网页服务

电脑安装 Python 后，在解压目录打开终端，执行：

```bash
python3 -m http.server 8080
```

如果电脑使用的是 Windows，也可以尝试：

```bash
python -m http.server 8080
```

### 3. 打开网页

浏览器访问：

<http://localhost:8080>

不要直接双击 `index.html`。直接打开可能导致 JavaScript 模块、音频或静态资源加载失败。

### 4. 停止服务

回到终端按：

```text
Control + C
```

即可停止本地网页服务。

## 四、功能说明

### 1. 概览

概览页可以查看：

- 词库总数
- 已加入学习的词数
- 待复习词数
- 未学习新词数
- 当前学习进度

概览页还提供：

- 学新词入口
- 开始复习入口
- 数据分析入口
- 韩语朗读音色选择

### 2. 学新词

进入“学新词”后：

1. 选择学习范围。
2. 查看韩语单词和罗马音。
3. 点击喇叭按钮听发音。
4. 点击“显示答案”或直接查看汉字和中文释义。
5. 根据记忆情况选择：

    - `记住`
    - `没记住`

也可以在卡片上左右滑动：

- 左滑：记住
- 右滑：没记住

卡片顶部会显示滑动提示：

```text
← 记住 · 没记住 →
```

### 3. 复习

复习页面会展示已经加入学习计划、并且到了复习时间的词。

使用步骤：

1. 先查看韩语词。
2. 点击“显示答案”。
3. 查看汉字、中文释义和例句。
4. 选择记忆结果，或者左右滑动评分。

如果选择“没记住”，该词会立即再次进入复习队列。

### 4. 反向练习

反向练习会给出中文和简体汉字，让你回忆对应的韩语词。

使用步骤：

1. 先看中文和汉字。
2. 回忆韩语词。
3. 点击“显示答案”。
4. 点击：

    - `记住`
    - `没记住`

反向练习主要用于额外强化记忆，不会改变正常复习计划。

### 5. 句子学习

句子学习按生活场景分类：

- 酒店
- 帮助 / 医疗
- 旅游
- 餐厅

每个场景句包含：

- 韩语句子
- 中文翻译
- 重点词
- 喇叭朗读按钮

句子学习不区分初级、中级或高级。

### 6. 例句和语法

学习或复习单词时，可以查看：

- 韩语例句
- 中文翻译
- 中文语法讲解

例句与语法讲解已离线内置，学习和复习时直接展示，无需联网。

### 7. 数据分析

进入“数据分析”后，可以查看：

- 已学词数
- 复习次数
- 记住率
- 待复习数量
- 近 14 天复习趋势
- 记忆曲线
- 词库完成度
- 平均记忆间隔

记忆曲线是根据当前 SRS 复习间隔计算的估算值，用于帮助了解整体记忆趋势，不代表医学或心理学意义上的精确测量。

## 五、学习记录保存逻辑

学习记录保存在当前浏览器的本地 IndexedDB 中：

```text
数据库：korean-hanja
数据表：reviews
```

数据只保存在当前设备和当前浏览器，不会自动上传，也不会跨设备同步。

### 记住

选择“记住”后：

- 单词会被标记为已加入学习
- 不会再出现在“学新词”
- 按 SRS 规则安排下一次复习

### 没记住

选择“没记住”后：

- 单词仍会被记录为已学习
- 不会重新出现在“学新词”
- 会立即进入“复习”
- 连续答对次数会重新计算

### 再次打开网页

只要没有清除浏览器网站数据：

- 已学过的词不会重新出现在“学新词”
- 到期的词会出现在“复习”
- “没记住”的词会再次进入复习
- 学习进度和数据分析记录会保留

如果执行以下操作，记录可能会消失：

- 清除网站数据
- 清除浏览器 IndexedDB
- 更换浏览器
- 更换设备
- 使用无痕窗口

## 六、朗读功能

点击喇叭按钮可以朗读韩语内容。

当前朗读策略：

1. 如果存在预生成音频，优先播放静态音频。
2. 如果没有对应音频，则使用浏览器或系统的韩语 TTS。

不同设备和浏览器提供的系统音色可能不同。概览页可以选择可用的韩语系统音色。

## 七、常见问题

### 看不到最新版本怎么办？

尝试强制刷新：

- macOS：`Command + Shift + R`
- Windows：`Ctrl + F5`
- 手机：关闭页面后重新打开
- 或使用无痕窗口访问

### ZIP 解压后打不开怎么办？

不要直接双击 `index.html`，在解压目录执行：

```bash
python3 -m http.server 8080
```

然后访问：

<http://localhost:8080>

### 为什么换设备后没有学习记录？

学习记录目前保存在本地浏览器，没有接入账号和云端同步，所以不会自动迁移到其他设备。

### 为什么例句可以离线显示？

例句和中文语法已经预先写入网页静态资源，运行时不需要调用模型或网络接口。
